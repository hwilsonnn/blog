A browser extension that converts visible page text into UwU style while avoiding script/style content and editable fields.

## Tech Stack

- JavaScript
- Browser Extension APIs
- HTML/CSS for popup UI

## Features

- Toggle auto-UwUify on and off from the popup
- Persists selected mode between sessions
- Applies automatically on newly opened pages when enabled
- Supports three intensity modes: Light, Medium, and Chaotic
- Avoids mutating script/style/noscript content and user-editable fields

## Notes

This project focuses on DOM-safe text transformation and user-controlled behavior, with a lightweight popup-based control surface.
