A weather dashboard that shows current conditions, hourly forecasts, and a 7-day outlook.

## Tech Stack

- **React** + **TypeScript**
- **OpenWeather API** for weather data
- **Recharts** for forecast graphs
- **Tailwind CSS** for styling

## Features

- 🌍 Location search with autocomplete
- 🌡️ Current conditions with feels-like temperature
- 📊 Interactive hourly forecast chart
- 📅 7-day extended forecast
- 🌓 Automatic dark/light mode

## What I Learned

Working with real-time APIs taught me a lot about loading states, error handling, and caching. I implemented a simple cache layer to avoid hitting rate limits.
