A simple markdown editor built for quick note-taking and document drafting.

## Tech Stack

- TypeScript
- Markdown rendering/parsing
- Browser file APIs

## Features

- Save files with keyboard shortcut (`Ctrl+S`) or download button
- Start from existing files using drag-and-drop into the editor
- Two working modes: edit and preview
- Toggle preview mode with `Esc`
- Generates a table of contents in preview mode without modifying the source document

## Notes

The project emphasizes a minimal writing workflow and practical local file interactions for everyday markdown editing.
